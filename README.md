# cpc-monthly-expense-rollup

把各年份資料夾裡的 `支出.xlsx` 明細，彙整成「每個月一列」的 `月份彙總.xlsx`。

## 資料夾結構

```
cpc-monthly-expense-rollup/
├── 點兩下執行月份彙總.py
├── 114/
│   ├── 支出.xlsx      ← 輸入
│   └── 月份彙總.xlsx  ← 輸出
└── 115/
    ├── 支出.xlsx
    └── 月份彙總.xlsx
```

年份資料夾用民國年命名。預設處理「今年」與「前一年」，找不到的資料夾會略過。

## 使用方式

```bash
python3 點兩下執行月份彙總.py            # 執行前自動 git pull，處理今年與前一年
python3 點兩下執行月份彙總.py 113        # 只處理指定年份（民國或西元皆可）
python3 點兩下執行月份彙總.py --push     # 產出後自動 commit + push
python3 點兩下執行月份彙總.py --no-pull  # 不要先 git pull
```

需要 Python 3 與 `openpyxl`：`pip3 install openpyxl`

## 輸出內容

- **月份彙總**：1～12 月每月一列，每個產品兩欄（數量 / 金額），最右欄為當月合計，最後一列為總結。沒有資料的月份留空。
- **月份明細**：長表（月份 / 產品名稱 / 數量 / 金額），每月有小計，最後有總結。

## 讀取規則

- 只讀含有「日期」「商品名稱」欄位的工作表，庫存表會自動略過。
- 日期空白的列沿用上一列日期；`2/30` 這類文字日期也會判讀月份。
- 月份以每列日期為準，不是以工作表名稱為準。
- 產品名稱裡的月份字樣會去掉合併（「勞保費-1月」→「勞保費」），加 `--keep-month-suffix` 可保留。
- 金額使用與來源相同的整數顯示格式，加總方式與來源「總金額」欄一致。
